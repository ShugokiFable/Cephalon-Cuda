[heading]Description[/heading]
Cephalon Cuda is a native Windows app ([b].NET 8 WPF[/b]) built as a serious alternative to Overwolf-heavy companions like AlecaFrame — without the bloat, without the storefront, and without touching the game process.

It watches Warframe [b]from the outside only[/b]:
[list]
[*]read-only tail of [code]%LocalAppData%\Warframe\EE.log[/code]
[*]DXGI Desktop Duplication + OCR for on-screen intel
[*]public APIs (world state, drops, market, relics, Mastery)
[/list]
Everything feeds a local SQLite knowledge layer and an optional streaming [b]OpenRouter[/b] AI advisor. Personal secrets (API keys) are encrypted at rest with [b]Windows DPAPI[/b].

Version [b]2.2 · Return Protocol[/b] adds a full returning-player command layer, automatic official-drop intelligence, evidence-aware build synthesis, Shop Guardian Platinum guardrails, and a rebuilt high-end interface with [b]eight live themes[/b] (Verv, Lotus, Orokin, Entrati, Corpus, Grineer, Void, High Contrast) plus custom accents that retheme open workspaces, overlays, and the Advisor instantly.

[b]100% external. 100% portable. One self-contained exe.[/b]
