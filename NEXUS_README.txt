CEPHALON CUDA 2.2 - RETURN PROTOCOL

INSTALL
1. Extract CephalonCuda.exe anywhere outside Program Files.
2. Run CephalonCuda.exe.
3. Complete the short first-run setup.
4. Add an OpenRouter key only if you want AI Advisor features.

THE APP AUTOMATICALLY FETCHES
- public Warframe item data
- official drop/acquisition data
- live world state
- relic data
- warframe.market catalog and price intelligence
- named-item live orders when relevant
- Mastery catalog
- configured licensed community build feeds

RETURNING PLAYER
Open Tenno Path, then JUST GOT BACK?. The app uses local EE.log activity, goals, Foundry state, roadmap progress and live source freshness to build a controlled return plan. It cannot see private account progression, so confirm anything it cannot know.

PLATINUM SAFETY
Use Shop Guardian before spending Platinum. Credits, routine resources, random mod packs, most base gear purchases and normal Foundry rushing are flagged as poor value. The app separates progression purchases from cosmetics and checks market alternatives when possible.

DATA LOCATION
%LocalAppData%\CephalonCuda

UNINSTALL
Delete CephalonCuda.exe. Delete the data folder above only if you also want to erase settings, local progress, caches and encrypted API credentials.

GAME SAFETY
The app does not inject, read game memory, automate input or play Warframe. It uses read-only EE.log events, visual capture/OCR, public endpoints and information you enter.
